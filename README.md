Website ini berisi:
- Tentang saya
- Pendidikan
- Keahlian
- Project
- Kontak
- Fakta tentang saya

## Struktur HTML
Website menggunakan beberapa elemen HTML5 semantik, yaitu:
- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`

Selain itu, website juga menggunakan:
- `<figure>` dan `<figcaption>` untuk gambar
- Form kontak
- Heading `h1`, `h2`, dan `h3`
- Link navigasi dengan anchor
- Meta description dan viewport
